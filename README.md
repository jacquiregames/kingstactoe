## 🛠️ Tech Stack

**Frontend:**
- **React 19** + **TypeScript**
- **Vite** (Build Tool & Dev Server)
- **Framer Motion** (Complex animations & layout transitions)
- **CSS3** (Custom keyframes, CSS Grid layouts)

**Backend:**
- **Python 3.x**
- **FastAPI** (API routing and WebSocket management)
- **Uvicorn** (ASGI server)
- **Pydantic** (Data validation)
